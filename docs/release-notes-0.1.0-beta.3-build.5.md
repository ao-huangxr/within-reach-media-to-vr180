# Within Reach Flat Media VR180 0.1.0 Beta 3 (macOS Build 5)

## 中文

主要修复：

- 修复macOS版本无法切换英文界面的问题；
- 中文和英文现在可以即时切换；
- 语言选择会在重启后保留；
- 补齐菜单、工作台、进度、对话框和错误信息的英文翻译。

本版本不改变VR180 Geometry、编码器或输出质量。

## English

Key fixes:

- Fixed an issue that prevented switching the macOS app to English.
- Chinese and English can now be switched instantly.
- The selected language is preserved after restart.
- Added English localization for menus, the workbench, progress messages,
  dialogs, and errors.

This update does not change VR180 geometry, codecs, or output quality.
